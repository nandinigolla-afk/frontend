MPAS Frontend

Overview

MPAS (Missing Person Alert System) is a web-based application designed to help communities report and track missing person cases. The platform allows users to submit missing person reports, receive region-based alerts, and provide information that may help locate missing individuals.

This repository contains the frontend of the MPAS application, developed to provide an intuitive and responsive user experience.

Features

* User Registration and Login
* Report Missing Person Cases
* View Active Missing Person Alerts
* Region-Based Alert Notifications
* Submit Sighting Reports
* Track Case Status Updates
* Responsive User Interface
* Secure Authentication

Technologies Used

* React.js
* JavaScript
* HTML5
* CSS3
* Axios
* React Router

Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd mpas-frontend
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm start
```

The application will run at:

```text
http://localhost:3000
```

Key Modules

# User Management

Allows users to register, log in, and manage their profiles.

# Missing Person Reporting

Enables users to submit detailed missing person reports.

# Alert System

Sends location-based alerts to nearby users regarding active missing person cases.

# Sighting Reports

Allows community members to submit information when they spot a missing person.
